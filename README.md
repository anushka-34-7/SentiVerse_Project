1. Project Title

Problem 10 – AI Sentiment Analyzer

Project Name: SentiVerse
Tagline: Where words meet emotions.




2. Problem Statement

The objective of this project is to develop an AI Sentiment Analyzer that analyzes user-provided text and identifies its sentiment.

The application classifies the entered text into one of three categories:

Positive
Negative
Neutral

The application also displays the analysis result along with a basic explanation of the detected sentiment.




3. Assigned Feature Set
Feature Set A

The assigned requirements for the project are:

Text Input
Positive/Negative/Neutral Classification
Display Result
Basic Explanation
4. Features Implemented
Core Features

1. Text Input
Users can enter a sentence or text into the SentiVerse interface for sentiment analysis.

2. Sentiment Classification
The application analyzes the entered text and classifies it as:

Positive
Negative
Neutral

3. Display Result
The detected sentiment is clearly displayed to the user after analysis.

4. Basic Explanation
The application provides a simple explanation describing why the entered text received the particular sentiment classification.

Additional Features

In addition to the assigned Feature Set A, the application includes:

Chatbot-style interface
Voice input
Image input
Analysis history
Clear history option
Settings section
Light Mode
Dark Mode
Responsive design
Modern and user-friendly interface

7. Important AI Prompts Used
Prompt 1 – Initial Project

Create an AI-powered sentiment analyzer web application named "SentiVerse" with the tagline "Where words meet emotions." The application should allow users to enter text and analyze whether the sentiment is positive, negative, or neutral.

Prompt 2 – Sentiment Analysis

Implement sentiment analysis that accepts user text, classifies it as Positive, Negative, or Neutral, displays the result clearly, and provides a basic explanation for the classification.

Prompt 3 – User Interface

Create a modern, premium, attractive, aesthetic and user-friendly chatbot-style interface for SentiVerse. Keep the design clean, well structured, responsive and easy to use.

Prompt 4 – History and Settings

Add History and Settings sections to the SentiVerse application while keeping the existing sentiment analysis functionality unchanged.

Prompt 5 – Theme

Add both Light Mode and Dark Mode to the SentiVerse application and allow the user to switch between the two modes from the settings.

Prompt 6 – Additional Input

Add voice input and image input functionality to the SentiVerse sentiment analyzer while maintaining the existing text sentiment analysis features.
